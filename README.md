# Emma Muhleman Portfolio

A professional portfolio website for Emma Muhleman, CFA, CPA, CQF, CIRA — Portfolio Manager and Global Macro Strategist at Ascend Investment Management LLC.

## Features

- **Responsive Design** — Fully responsive layout optimized for desktop, tablet, and mobile devices
- **Modern Aesthetic** — Dark navy and charcoal background with gold/amber accents, professional typography
- **Smooth Navigation** — Sticky navigation with smooth scroll behavior between sections
- **Comprehensive Content** — Includes professional background, published research, media appearances, financial models, and education
- **Single Page** — Fast-loading single HTML file with embedded CSS and minimal JavaScript

## Sections

1. **Hero** — Name, title, designations (CFA, CPA, CQF, CIRA), tagline, and social links
2. **About** — Professional overview, current role at Ascend Investment Management, credentials
3. **Published Research** — Cards featuring major research publications and analyses
4. **Media & Public Speaking** — Fox Business appearances and conference speaking engagements
5. **Financial Models** — Placeholder cards for downloadable Excel models (coming soon)
6. **Professional Background** — Career timeline spanning 11+ years in investment management
7. **Education & Certifications** — Academic degrees (NYU, Notre Dame) and professional designations
8. **Contact** — Email and LinkedIn links

## Technology Stack

- **HTML5** — Semantic markup
- **CSS3** — Responsive design with CSS Grid and Flexbox
- **JavaScript** — Smooth scroll navigation and active link highlighting
- **Google Fonts** — Inter (body), Playfair Display (headings)

## Hosting

This site is designed to be hosted on GitHub Pages. The repository is configured to serve the `index.html` file directly.

## Local Development

1. Clone the repository:
   ```bash
   git clone https://github.com/EmmaMuhleman1/portfolio.git
   cd portfolio
   ```

2. Open `index.html` in your browser to view the site locally

## Deployment to GitHub Pages

The site is automatically hosted on GitHub Pages at:
```
https://emmamuhleman1.github.io/portfolio/
```

## Customization

All styling is embedded in the `<style>` tag within `index.html`. Key color variables:

- `--navy: #1a2332` — Primary background
- `--gold: #d4a574` — Primary accent color
- `--charcoal: #2d3e50` — Secondary background
- `--text-light: #f0f0f0` — Primary text color
